# Les Niçoises

Site éditorial de la Côte d'Azur.

## Publication
Le dépôt GitHub est déployé automatiquement sur OVH par webhook.

## Structure
- `index.html` : homepage
- dossiers de rubriques : pages et articles
- `en/` : version anglaise
- `assets/` : styles et scripts communs
- `.htaccess` : HTTPS, redirection www et désactivation du listing des dossiers
- `sitemap.xml` et `robots.txt` : SEO technique

## Règles éditoriales
Voix utile, locale, caustique par touches, jamais brochure touristique.
Pas de fausse expérience personnelle.
Pas de tiret cadratin dans les textes.

## Homepage master
La home utilise `assets/hero-les-nicoises.jpg`, avec les cinq Niçoises de face sur les chaises bleues. Le bandeau de navigation est en HTML, pas imprimé dans l’image.
