LE VERDICT MAMETAS

Pour MIPIM, payez d’abord la géographie, puis les étoiles. Palais/Croisette si vous voulez marcher partout. Centre-gare pour le meilleur compromis. Antibes est le plan B intelligent. Nice est viable, moins séduisante après un dîner tardif.
