Google data use

Mametas Reporting — privacy notice

This notice applies only to Mametas Reporting, a private Google Apps Script used by the operator of mametas.com. It is separate from the website's visitor privacy policy.

What data is accessed

When the operator explicitly authorises access through Google OAuth, the script reads Google Analytics 4 aggregate website performance data, such as sessions, engagement, traffic sources, landing pages and dates. It also reads Google Search Console search performance data, including search queries, page URLs, clicks, impressions, click-through rates, average ranking positions and dates.

The script requests Google Sheets edit access to write reports to a particular spreadsheet controlled by the same operator. Although Google's permission wording covers spreadsheets more broadly, the current script uses only the configured reporting spreadsheet. The script does not request access to Gmail, contacts, advertising accounts or Google Drive files outside that spreadsheet.

Purpose and lawful use

These data are used solely to monitor mametas.com's organic search visibility and website traffic, and to support editorial decisions. The reporting script does not personalise advertising, profile individual visitors or sell Google user data.

Where the data goes

API requests are made directly to Google Analytics and Google Search Console. The resulting metrics are saved in a private Google Sheets spreadsheet in the authorised Google account. Google Apps Script runs the scheduled refresh using the operator's permissions. The script does not send these metrics to the public Mametas site or to an external reporting vendor.

Access to the spreadsheet is determined by its Google Drive sharing settings. The spreadsheet is not intentionally published on the Mametas website.

Retention and deletion

The automated Google reports use rolling 28-day windows and replace previous report contents when refreshed. Data persist in Google Sheets until overwritten or deleted by the operator. Google may retain execution and authentication logs under its own policies. The operator can delete the report spreadsheet or disable the Apps Script schedule.

Permissions and revocation

The operator grants access through the Google authorisation screen and can revoke the application's access from their Google Account's third-party connection settings. Revoking access stops future retrieval but does not automatically erase report cells already stored in Google Sheets.

Data-sharing and contact

The reporting script does not sell the accessed Google data or disclose them to advertising platforms. Data are processed using Google's services under the operator's account permissions. For questions or deletion requests relating to this private utility, contact mametas.riviera@gmail.com.
